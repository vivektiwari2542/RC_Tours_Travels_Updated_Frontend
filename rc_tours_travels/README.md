# R.C Tours & Travels — Travel Website Frontend

A responsive multi-page travel website frontend made with HTML, CSS and vanilla JavaScript.

## Included pages
- `index.html` — homepage and combined search form
- `trains.html` — train search form
- `flights.html` — flight search form
- `buses.html` — bus search form
- `hotels.html` — hotel search form
- `offers.html` — sample offers/travel ideas
- `about.html` — about page
- `contact.html` — enquiry form
- `results.html` — sample results page

## Run locally
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Test the navigation, date validation, service tabs, search results sorting and contact enquiry form.

## Important limitations
- Search results and prices are illustrative examples only; they are not live quotes.
- No real train, flight, bus or hotel availability is queried.
- No ticket or hotel booking is made.
- The contact form does not send email. Connect a trusted backend or form provider before collecting real user information.
- The Login / Register link is a placeholder; authentication is not implemented.
- The external Font Awesome and homepage background image require internet access.
